# Flushing Journal Flask App

## Run

```bash
pip install flask
python app.py
```

Open http://127.0.0.1:5000

The app includes an 11x17 landscape sheet, Leaflet map, editable fields, tabs, toolbar, and PDF download button.

Project-wide default flushing settings and unit conversions are defined in `constants.py`. The backend and the initial UI values use these shared definitions.

Uploaded network models are converted to a steady-state `BaseModel.inp`. INP files generated by sequence runs are saved beside it and grouped in an `inpFiles/` folder in downloaded project ZIPs. Simulation results are saved as JSON-formatted `results.txt`, included in the project ZIP, and restored for playback when the project is uploaded again.

Set the lateral diameter, lateral roughness, and maximum hydrant search distance in the Connect Hydrants dialog. The Options toolbar reports the effective settings; flushing velocity ratio, minimum flush velocity, volume turnovers, and default orifice diameter are passed to the simulation and saved in project ZIP metadata.

Set the maximum valve snap distance in the Snap Valves dialog. Valves farther from the nearest pipe than this distance are left at their uploaded or moved location and are not mapped to a model pipe.

After running sequences, use the map playback controls to step or automatically animate through operations and view valve, pipe, and hydrant states. Enable **Show pipe velocities** to color every pipe by that operation's simulated velocity (ft/s); velocities are stored in the project results file for playback.

Each operation's **Options** dialog can override the project-default orifice diameter, start-to-flush velocity ratio, minimum flush velocity, and volume turnovers. Leave any field blank to use its project default. Operation-specific settings are included in project ZIPs.

Use the Select button beside Edit project to select valves and hydrants on the map. Click to select one, Shift-click to add more, and Ctrl/Cmd-click to remove a selection; then use an operation's Open Valves, Close Valves, or Open Hydrants button to add the selected IDs.
